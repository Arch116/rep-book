# Rep Book

A personal workout planner and log that works on phone and laptop.

- Plan routines (sets, reps, weight, warm-ups, supersets) and a weekly schedule
- Log workouts with plate math, rest timer, "reps left" effort tracking and automatic weight suggestions
- History, calendar, personal records, estimated 1-rep max and progress charts
- Edit workouts as you go (drop sets, remove sets or exercises, update the routine to match), fix dates and times, and log workouts from before you had the app
- Optional burnout finisher at the end of every workout, with a goal that rises as you beat it
- Works offline and can be added to your home screen
- Optional sync between devices with a free Supabase account (see `supabase-setup.sql`)

Plain HTML, CSS and JavaScript: no build step. Open `index.html` through any static web server.
